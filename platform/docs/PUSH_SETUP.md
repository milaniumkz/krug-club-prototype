# Уведомления избранного

Сервер создаёт уведомление при одобрении модератором новой акции или увеличения процента скидки. Черновики, отклонённые изменения и уменьшение скидки рассылку не создают. Получатели — действующие участники, добавившие заведение в избранное, с учётом доступных организаций. Для будущей даты начала отправка планируется на начало дня в Казахстане. Уникальная пара участник/версия акции защищает от дублей.

Уведомления сохраняются в личном разделе приложения. Серверные API регистрации устройств, выбора языка ru/kk, отключения токена и очередь доставки готовы. Выход из клуба отключает зарегистрированные устройства. Worker проверяет действующее членство и наличие заведения в избранном перед отправкой. Ошибки доставки повторяются с задержкой; токены и тела ответов FCM не записываются в журналы.

Настоящая доставка на телефон включается после предоставления конфигурации Firebase/Apple. До этого worker не запускается и реальные push не отправляются.

Нужно предоставить:

- Firebase-проект: https://console.firebase.google.com/ . Для Android — конфигурацию приложения `google-services.json`; для iOS — `GoogleService-Info.plist`. Идентификатор пакета/Bundle ID: `kz.qazaqmetal.qazaqmetal`.
- Серверный Firebase service account с правом отправки FCM. Его JSON хранится только на сервере вне репозитория.
- Для iOS — Apple Developer, Team ID, Key ID и APNs `.p8` для настройки раздела Cloud Messaging в Firebase; разрешённая возможность Push Notifications в provisioning.

После получения файлов нужно связать нативный Firebase Messaging SDK с конфигурациями, зарегистрировать токен через `POST /api/me/push-devices`, настроить канал Android `favorite_offers`, запросить разрешение пользователя и обработать открытие заведения по `venue_id`. Эти шаги требуют настоящих конфигураций приложений и проверки на физических устройствах.

Worker подготовлен в `server/app/push_worker.py`; сборка — `server/Dockerfile.push`. Дополнительный compose-файл — `compose.push.yaml`, профиль `push`. Приватный файл должен быть читаем UID 10001 внутри контейнера; родительская папка на сервере закрыта. Не публиковать ключ и не включать его в APK.

Пример после безопасной установки ключа:

```bash
cd /opt/qazaqmetal/current
export FIREBASE_ADMIN_FILE=/opt/qazaqmetal/shared/secrets/firebase_admin.json
docker compose -f compose.yaml -f /opt/qazaqmetal/shared/compose.production.override.yaml -f compose.push.yaml --profile push up -d --build push
```

Принудительное завершение сессии работает отдельно от FCM: PostgreSQL NOTIFY будит ожидающий запрос приложения сразу после фиксации изменения. При обрыве соединения приложение повторно проверяет доступ. PIN/биометрия не заменяют серверную проверку членства.
