# QMET+: управление приложением с сервера

Текущий адрес сохраняется: https://qazaqmetal.109.235.119.144.sslip.io.
Идентификаторы Android/iOS и формат действующих QR не меняются.

## Администратору

Откройте административный кабинет → «Настройки приложения». Измените необходимые поля и сохраните. Доступ к записи есть только у администратора. Форма защищена от перезаписи одновременных правок: при конфликте загрузите актуальную версию и повторите нужные изменения.

С сервера задаются название и загруженный логотип внутри интерфейса, основной цвет и светлый фон, тексты и подписи меню на русском и казахском, порядок блоков главной, включение QR/карты/баннеров/уведомлений, контакты, FAQ, политика конфиденциальности, условия использования и сообщение о технических работах. Данные партнёров, скидки, изображения и модерация продолжают работать через существующие кабинеты.

Изменения проверяются по ETag при запуске, возвращении в приложение и раз в две минуты. Последняя корректная конфигурация хранится локально; при ошибке сети или неизвестном формате сохраняются рабочие настройки. Изменения оформления не завершают авторизацию и не сбрасывают PIN. Отключение функции проверяется и сервером.

## Совместимость и восстановление

Минимальная и последняя версии задаются отдельно для Android/iOS и участника/партнёра. Номер — числовой build из pubspec, например 20, а не строка 2.4.0. Укажите действительную HTTPS-ссылку на опубликованное обновление до повышения минимальной версии. Веб-версия и админка остаются доступны для исправления настройки. Не повышайте минимум выше доступной пользователям сборки.

`GET /api/app-config` возвращает schema_version, revision, portal, settings и etag; `If-None-Match` поддерживает 304. `PUT /api/admin/app-config` принимает settings и expected_revision, конфликт возвращает 409. Изменённые поля фиксируются в аудите. Миграция 0003 создаёт таблицу настроек без удаления существующих пользователей, сессий или QR.

## Когда всё же потребуется новая сборка

Новые нативные функции и экраны, разрешения ОС, библиотеки камеры/геолокации, исправления самого клиента, значок и название на домашнем экране телефона требуют выпуска обновления. Удалённая конфигурация содержит только проверяемые данные, без загружаемого исполняемого кода. Изменения API должны сохранять совместимость с уже установленными версиями.

## Сборка и публикация

Участник: `python platform/scripts/build_member.py --platform android --mode debug`.
Партнёр: `python platform/scripts/build_partner.py --platform android --mode debug`.
Проверенная публичная API-ссылка передаётся сборщиком явно; адрес эмулятора для распространения не используется.

Для Google Play подготовьте собственное подписание (приватный android/key.properties и keystore вне Git), затем `python platform/scripts/build_member.py --platform android --mode release --bundle`. Для iOS нужны macOS/Xcode, Apple Developer, signing/provisioning и APNs. Неподписанная проверочная сборка: `python platform/scripts/build_member.py --platform ios --mode release --no-codesign`.

Перед отправкой заполните реальные контакты оператора, юридические документы и store URL, проверьте камеры, геолокацию, PIN и доставку push на физических устройствах. В профиле запрос удаления создаёт обращение администратору; он не удаляет членство автоматически. Тестовый sslip-адрес сохранён по решению заказчика; его смена в уже опубликованном бинарном клиенте потребует новой сборки.
