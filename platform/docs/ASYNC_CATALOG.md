# Асинхронное чтение каталога

GET /api/catalog работает с AsyncSession PostgreSQL и теми же SQLAlchemy-моделями. Сессия и права проверяются функцией current_user из общего модуля безопасности при каждом запросе. Затем выполняются прежние проверки обязательной смены пароля и роли участника. Кэшируется только ответ каталога, не авторизация.

Пул ограничен 10 соединениями на процесс без переполнения; ожидание соединения — до 5 секунд. Пул корректно закрывается при остановке. Запросы записи, смена паролей, QR, история и фоновые уведомления сохраняют прежние транзакции. Вместе с синхронными пулами и двумя процессами API базовый лимит соединений остаётся ниже стандартных 100 PostgreSQL.

Для PostgreSQL все 37 серверных тестов проходят с реальным асинхронным драйвером на маршруте каталога. SQLite для локальной разработки использует прежний синхронный сеанс через рабочий поток. Подмена проверки доступа или кэш сессий не применялись. Численные результаты публикуются отдельно, ожидаемая скорость не выдаётся за замер.
