# QAZAQMETAL 2.2.0 — тестирование

Участники: https://qazaqmetal.109.235.119.144.sslip.io

Партнёры: https://qazaqmetalpartners.109.235.119.144.sslip.io

Администрация: https://qazaqmetaladmin.109.235.119.144.sslip.io

В приложении участника доступны только табельный номер и пароль. Кабинеты партнёров и администрации принимают логин и пароль, роли проверяются сервером по адресу кабинета. Телефон для входа не используется.

После первого входа нужно установить личный пароль от 6 символов, отличающийся от временного, затем PIN из 6 цифр для текущего устройства. PIN запрашивается при повторном открытии сохранённой сессии. На Android/iOS после настройки PIN можно включить доступную биометрию; в браузере используется PIN. Забытую локальную блокировку можно сбросить через выход и повторный вход с паролем аккаунта. При отсутствии связи сброс не обходит действующий PIN.

Русский/казахский переключаются на входе и в профиле; выбор сохраняется локально. Для заведений доступны отдельные казахские поля, проходящие ту же модерацию. Демо-карточки дополнены переводами. Карта использует бесплатные OpenStreetMap/OpenFreeMap с выбором `name:ru` или `name:kk` и обязательной атрибуцией.

Нижнее меню участника сохраняется в карточках, избранном, истории и настройках. Сканер находится в меню QR, сам определяет заведение. Оставлены камера, переключение камеры и повторная попытка; фонарик и ручной ввод убраны. Произвольные URL из QR не открываются.

Демонстрационные заведения: ресторан «Сад» (15%) и цветочная мастерская «Лепесток» (10%). Это тестовые предложения, не подтверждение реальной скидки. Для печати выдаются два PNG и двухстраничный PDF. Состояние QR проверяется перед выдачей. Данные заведений, фотографии, избранное, история и права находятся в PostgreSQL/постоянном uploads volume.

Участники 01/02 создаются с временным 123456; если пользователь уже сменил пароль, деплой его не сбрасывает. Партнёрские тестовые логины partner01/partner02. Реальные пользователи через импорт получают уникальные случайные временные пароли. Администратор получает отдельный случайный пароль через приватную передачу.

Увольнение/блокировка удаляет сессии. Приложение получает событие отзыва и возвращает экран входа без нажатия пользователем кнопки. После потери связи проверка повторяется. Истёкшее членство также не позволяет войти; надпись «Членство активно» на главной не показывается.

Уведомления избранного и очередь отправки готовы; для настоящего push нужны Firebase/APNs и нативная конфигурация, см. PUSH_SETUP.md. Не заявляется доставка на физические телефоны до этой настройки.

Сборки:

```bash
cd platform/client
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter build web --release --no-web-resources-cdn --no-tree-shake-icons --output=../web
flutter build apk --debug --dart-define=API_BASE_URL=https://qazaqmetal.109.235.119.144.sslip.io
# На macOS с Xcode:
flutter build ios --release --no-codesign --dart-define=API_BASE_URL=https://qazaqmetal.109.235.119.144.sslip.io
```

Debug APK подписан тестовым ключом. Для App Store/Google Play нужны подписи магазинов и проверка на физических устройствах. Успешная компиляция не является проверкой камеры, Face ID или отпечатка пальца. API-тесты запускаются только в изолированной базе `qazaqmetal_test`; живые проверки используют уникальные временные QA-аккаунты и удаляют только свои записи. Итоговый протокол прикладывается к выпуску.
