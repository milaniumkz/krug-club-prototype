# PIN 2.2.1+14

Собственная цифровая панель 0–9 без системной клавиатуры: шесть точек, удаление цифры, автоматическое подтверждение. Создание и повторный ввод представлены отдельными шагами. Такая же панель используется при смене PIN в профиле. Поддерживается аппаратная клавиатура, доступные подписи и русский/казахский интерфейс.

PIN действует в пределах авторизованной сессии на устройстве. Перезапуск приложения и смена пароля в активной сессии сохраняют PIN. Выход, отзыв сессии и новая авторизация по учётным данным очищают прежний PIN, счётчик попыток и настройку биометрии. После новой авторизации требуется создать новый PIN. После пяти ошибок предусмотрена блокировка на 30 секунд.

Проверено: Flutter analyzer; 26 Flutter-тестов, включая отсутствие EditableText/системной клавиатуры, неверное подтверждение, удаление цифры, создание/сохранение/повторный ввод, жизненный цикл PIN, размеры 320/390/768. Android debug APK и web собраны. Физические устройства и биометрия требуют проверки на телефонах.

Сервер: потоковая ASGI-защита вместо BaseHTTPMiddleware и асинхронные проверки ролей без операций ввода-вывода. На каждом запросе сохранена проверка сессии в базе; кэш авторизации не добавлялся. Результаты производительности публикуются отдельно в reports.
