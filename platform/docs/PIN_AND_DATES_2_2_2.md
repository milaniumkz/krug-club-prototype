# Версия 2.2.2+15: PIN и календарь

PIN и настройки биометрии доступны только участникам. Кабинеты администратора и партнёра открываются по действующей сессии без создания или ввода PIN, в том числе после обновления страницы. Вход по паролю и обязательная смена временного пароля остаются.

У участника обновление страницы запрашивает PIN сохранённой сессии. Полный выход и новая авторизация требуют создать новый PIN.

Начало и окончание предложений выбираются календарём без ручного ввода. Формат на экране ДД.ММ.ГГГГ; API получает ISO YYYY-MM-DD. Календарь ограничивает даты границами выбранного периода, дату можно очистить. Фильтры статистики также используют календарь и ДД.ММ.ГГГГ. Даты в предложениях, истории, сессиях и журнале действий отображаются в привычном формате. CSV/API сохраняют машинный формат. Календарь локализован на русский и казахский.

Проверки: Flutter analyzer; 33 Flutter-теста, включая три роли, повторное открытие, доступность PIN-настроек, выбор и очистку даты, сохранение ISO и отображение ДД.ММ.ГГГГ. Физические устройства требуют отдельной проверки.
