# Публикация Android, iOS и сайта

## Идентификаторы

Текущий bundle/application ID: `kz.qazaqmetal.qazaqmetal`. До первой публикации подтвердите его у владельца аккаунтов магазинов. После выпуска идентификатор нельзя менять без нового приложения.

## Android

- Android 7 / API 24 и новее.
- Разрешения: Интернет, камера, примерная/точная геолокация только при использовании карты. Выбор фото через системный интерфейс.
- Создайте собственный upload keystore; храните резервную копию и пароли вне репозитория.
- Создайте `android/key.properties` по примеру, соберите AAB с реальным HTTPS API_BASE_URL. Release не использует debug key.
- В Play Console заполните описание, графику, возрастной рейтинг, Data Safety, privacy URL и тестовый доступ для проверки модератором. Организуйте закрытый тест согласно требованиям конкретного аккаунта.

## iOS

- Нужны macOS, Xcode, CocoaPods и Apple Developer account; минимальная версия iOS 15.5.
- В `Runner.xcworkspace` выберите Apple Team и подтвердите Bundle Identifier.
- `flutter config --no-enable-swift-package-manager` (этот проект содержит Podfile); `flutter pub get`; `cd ios && pod install && cd ..`.
- Для проверки компиляции без ключей: `flutter build ios --release --no-codesign --dart-define=API_BASE_URL=https://your-domain.kz`.
- Для магазина: `flutter build ipa --release --dart-define=API_BASE_URL=https://your-domain.kz` после настройки сертификатов и provisioning. Загрузите через Xcode Organizer/Transporter в App Store Connect, проверьте в TestFlight.
- Info.plist содержит тексты разрешений камеры, геолокации и библиотеки фото. Заполните App Privacy фактической политикой оператора и проверенными сведениями SDK. Введите контакты и URL правил/конфиденциальности владельца сервиса.
- Камеру, фото, геолокацию, keychain и возврат из фона обязательно проверять на физических iPhone. Успех веб-тестов не является этой проверкой.

## Проверка перед выпуском

Первый вход и временный пароль; сохранение сессии после перезапуска и обновления; выход и отзыв доступа; запрет доступа после увольнения; все пять разделов нижнего меню; карта с разрешённой/запрещённой геолокацией; камера с разрешением/отказом; неверный/отозванный QR; действующая/просроченная акция; модерация всех типов контента; фотографии; системная кнопка «Назад»; клавиатура; крупный текст; альбомная ориентация; фон/возврат; нестабильная сеть.

Серверный хостинг, домен, доступы магазинов, реальные аккаунты работников и подтверждённые материалы партнёров не встроены в исходники. Они настраиваются в ходе публикации. Камерный сценарий браузера с искусственным видеопотоком, если он выполнен, не заменяет проверку камеры телефона.
