# Круглый логотип и иконки QMET+

logo-circle.png — согласованный круглый вариант без внешних белых полей. Белое кольцо с надписью внутри эмблемы сохранено.

Android: прозрачные круглые legacy/round PNG и adaptive icon с голубым фоном #02A3DA; название приложения и package ID сохранены. Уведомления продолжают использовать отдельный монохромный ic_stat_qmetplus.
iOS: все размеры AppIcon экспортированы как непрозрачный RGB PNG, фон за кругом — голубой, внешних белых углов нет.
Web: favicon, обычные и maskable PWA-иконки обновлены.

Повторный экспорт: `bash platform/scripts/generate_app_icons.sh` (ImageMagick 7 и Python 3). Команда экспортирует изображения, но не собирает APK/IPA.

Изменение уже установленной нативной иконки потребует будущего обновления приложения. На этом этапе новая сборка APK остановлена по указанию заказчика.
