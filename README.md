# КРУГ · прототип клубной карты

Интерактивный дизайн-прототип мобильного клуба: цифровая карта участника, каталог партнёров, привилегии и демонстрационный сценарий QR-проверки.

**Статус: демонстрационный frontend. Это не готовое приложение для реальных участников и партнёров.**

Демо: https://krug-club-concept.milaniumkz.chatgpt.site

## Что можно попробовать

- Переключаться между главной, партнёрами, выгодами и профилем.
- Искать партнёров, фильтровать категории и сохранять избранное.
- Открывать карточки мест и условия демонстрационных скидок.
- Переключать статус членства: активное или истёкшее.
- Проходить успешный и отклонённый сценарии QR-проверки.
- Завершать демо-посещения и смотреть локальную историю.

## Запуск

Нужны браузер и Python 3. В каталоге проекта выполните:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8000. Установка пакетов, сборка и переменные окружения не нужны.

Можно использовать любой другой статический HTTP-сервер. Прямое открытие `index.html` также показывает интерфейс, но работа `localStorage` для `file://` зависит от браузера.

## Файлы

- `index.html`: структура страницы и навигация.
- `styles.css`: адаптивные стили для мобильного и настольного экрана.
- `app.js`: интерфейс, вымышленные данные и логика демонстрации.
- `favicon.svg`: иконка проекта.

Проект использует обычные HTML, CSS и JavaScript без фреймворков. Иллюстрации и иконки заданы встроенным SVG.

## Ограничения

- Нет backend, базы данных, регистрации, авторизации или реальных аккаунтов.
- Нет оплаты, подписок и продления членства.
- QR-картинка декоративная: камера не включается, настоящий QR-код не считывается.
- Статус членства переключается в браузере и не проверяется на сервере.
- Нет кабинета партнёра, защиты от повторного использования или подтверждения сотрудником.
- Все имена участников, номера карт, заведения, адреса, расстояния и предложения вымышлены. Экран успешной проверки не даёт права на скидку.
- Сроки членства фиксированы для демонстрации и не обновляются автоматически.

Для реального запуска потребуются отдельные backend и база данных, аутентификация, безопасная проверка членства и QR-кодов, роли партнёров и администратора, обработка персональных данных и тестирование.

## Данные и внешние ресурсы

Избранное и история демо-посещений сохраняются только в `localStorage` этого браузера, в ключах `krug-favorites` и `krug-visits`. Между устройствами они не синхронизируются. Для сброса удалите данные сайта в настройках браузера. Выбранный статус членства после перезагрузки возвращается к активному.

Приложение не отправляет данные участника на сервер и не подключает аналитику. CSS загружает шрифт Manrope через Google Fonts, поэтому браузер делает сетевые запросы к сервису шрифтов. Если он недоступен, используется системный шрифт. Настройки и журналы выбранного хостинга определяются самим хостингом.

## Проверка

Проверка синтаксиса JavaScript, если установлен Node.js:

```sh
node --check app.js
```

Для ручной проверки откройте все четыре раздела, измените фильтр каталога, добавьте место в избранное и перезагрузите страницу. Затем пройдите QR-демо с активным и истёкшим членством, проверьте историю, закрытие окон кнопкой и клавишей Escape. Проверьте экран телефона и настольного браузера. Автоматического набора тестов и CI в этой версии нет.

## Публикация

Все четыре файла можно разместить на статическом хостинге в одном каталоге. Не добавляйте в публичный репозиторий файлы `.env`, учётные данные, служебные настройки хостинга или реальные данные участников.

Отдельная лицензия на использование и распространение в этой версии не назначена.
